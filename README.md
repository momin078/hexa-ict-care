## 🚀 কীভাবে ওয়েবসাইটটি দেখবেন (How to View)

### অপশন ১: সরাসরি ব্রাউজারে ওপেন করুন
আপনার কম্পিউটারের ফাইল ম্যানেজারে গিয়ে নিচের ফাইলটিতে ডাবল ক্লিক করুন:
```
/home/mrmomin/.gemini/antigravity/scratch/ict-tuition-website/index.html
```

### অপশন ২: লোকাল সার্ভার চালিয়ে দেখতে চাইলে (Python)
টার্মিনালে এই কমান্ডটি চালান:
```bash
cd /home/mrmomin/.gemini/antigravity/scratch/ict-tuition-website
python3 -m http.server 8080
```
এরপর ব্রাউজারে `http://localhost:8080` ওপেন করুন।
